One sentence, 127 characters, on the best advice I ever received:

> Dad told me in 2008 that dreading Sunday night means your job is a cage, not a career, and I stayed in mine for six more years.

Dad named the test in 2008 — Sunday-night dread means the job is a cage, not a career — and the landing is the self-own: I knew, and I stayed six more years anyway. A real person, a real year, a real consequence.

## Run it

```sh
node main.ts
```

`main.ts` writes the single sentence to `/output/entry.txt`. Node 22 standard library only, fully deterministic: the same bytes on every run, no network, no clock, no randomness.
